# Shepherd
Shepherd is a medical document summarizer built for the AccelR8 Prairie AI Hackathon 2026 (Healthcare 2 challenge). It converts complex, jargon-heavy discharge summaries into two outputs from a single source: a plain-language summary a patient can actually understand, and concise key highlights for clinicians. Its distinguishing feature is a source-grounding layer that flags any claim in the generated summary not traceable to the original document — catching AI fabrications before they reach a patient. Shepherd is a documentation aid, not a diagnostic tool: it summarizes and simplifies source content only, never diagnoses, prescribes, or adds medical information. All data used is synthetic.
